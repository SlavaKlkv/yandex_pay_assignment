# Разбор запроса на создание заказа

## Ошибки

1. `orderId` передан числом (`930318`), а API ожидает строку. Этот идентификатор используется для дальнейшей работы с заказом и как ключ идемпотентности.
2. Оба `quantity.count` переданы числами (`1` и `4`), хотя схема API задает тип `string<double>`. Следует передавать `"1"` и `"4"`.
3. Если магазин подключает только Сплит, `availablePaymentMethods: ["CARD"]` противоречит сценарию: форма оставит только полную оплату картой. Нужно `availablePaymentMethods: ["SPLIT"]`.
4. Redirect URL непригодны для внешнего покупателя: `onError` указывает на intranet-домен, а `onSuccess` - на внутренний трекер. Даже если строки проходят формальную валидацию, пользователь извне не должен попадать на недоступные или служебные страницы. Нужны публичные HTTPS-страницы магазина.

## Проверка арифметики

- Первая позиция: `22990.54 x 1 = 22990.54`.
- Вторая позиция: `5500.00 x 4 = 22000.00`.
- Корзина: `22990.54 + 22000.00 = 44990.54`.

Суммы согласованы. Поле `unitPrice: "24000"` у второй позиции трактуется как цена одной единицы до скидки, а `discountedUnitPrice: "5500"` - цена одной единицы после скидки. Это необычно большая скидка, но само по себе не нарушает арифметику `total`. Для прозрачности в исправленном минимальном примере поле `unitPrice` оставлено, а денежные значения нормализованы до двух знаков после запятой.

## Исправленный пример для оплаты только через Сплит

```json
{
  "availablePaymentMethods": ["SPLIT"],
  "metadata": "Не забыть пробить чек",
  "purpose": "Проведение оплаты покупки",
  "cart": {
    "items": [
      {
        "discountedUnitPrice": "22990.54",
        "productId": "126329",
        "title": "Роттердам Velvet Pink",
        "total": "22990.54",
        "quantity": {
          "count": "1"
        }
      },
      {
        "discountedUnitPrice": "5500.00",
        "productId": "126330",
        "title": "Роттердам Velvet Blue",
        "total": "22000.00",
        "unitPrice": "24000.00",
        "quantity": {
          "count": "4"
        }
      }
    ],
    "total": {
      "amount": "44990.54"
    }
  },
  "currencyCode": "RUB",
  "orderId": "930318",
  "redirectUrls": {
    "onError": "https://shop.example/order/930318/error",
    "onSuccess": "https://shop.example/order/930318/success",
    "onAbort": "https://shop.example/order/930318/abort"
  },
  "ttl": 1800
}
```

`shop.example` здесь является безопасным демонстрационным доменом. Перед реальным запуском его необходимо заменить на публичный домен магазина.
